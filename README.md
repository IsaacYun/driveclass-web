# DriveClass Web

드라이브클래스 Android 앱의 브라우저 시연 버전입니다. Pleos 색·컴포넌트 CSS, Asta Sans, 앱 아이콘과 실제 샘플 음원을 사용합니다.

접속: https://isaacyun.github.io/driveclass-web/

## 실행

`npm start` 후 http://localhost:4173 을 엽니다. 빌드나 API 키가 필요 없는 정적 사이트입니다. `npm test`는 편성 엔진을 검증합니다.

## 시연

1. 재생 → DEMO → 주행 중 켜기 → 정체 +8분: 현재 블록을 유지하며 복습을 추가합니다.
2. DEMO → 목적지 → 6분: 뒤쪽 블록을 줄입니다.
3. DEMO → 목적지 도착: 재생을 멈추고 정리합니다.
4. 정차 상태에서 오늘의 정리의 ▶를 누르면 원문과 번역이 차례로 재생됩니다.
5. 중간에 주차 후 이어 듣기, 또는 페이지를 다시 열어 저장된 위치를 복원합니다. 자동 재생이 차단되면 재생 버튼을 누릅니다.

실제로 재생 가능한 콘텐츠는 영어 회의 표현 3회입니다. 다른 과목·회차는 Android 앱과 동일하게 샘플 목록입니다. 표현 수집 시점은 Android와 동일한 근사 cue이며, 건너뛴 구간은 수집하지 않습니다.

## 테슬라 확인

차량 브라우저에서 위 HTTPS 주소를 열고 재생을 누릅니다. 진단에서 위치·속도 수신을 요청할 수 있습니다. 지도 화면으로 전환했다 돌아오면 재생 진행과 pause/stalled 기록을 확인할 수 있고 JSON으로 내려받을 수 있습니다. GPS 좌표는 서버로 보내거나 진단 기록에 저장하지 않습니다.

테슬라 내비 ETA·기어 신호는 연결되지 않습니다. DEMO로 입력합니다. Media Session API 지원 여부와 실제 차량 버튼 동작은 별개이며, 주행 중 오디오·백그라운드 유지·GPS 속도는 실차 확인이 필요합니다. 화면 조작과 설정은 정차 중 진행하세요.

학습 기록과 재생 위치는 이 브라우저의 localStorage에만 저장됩니다. 서버·계정·분석 추적기는 없습니다. GitHub Pages에서 정적 파일을 제공합니다.

## 출처

Android 앱 소스 스냅샷 `102cbd8`의 편성 엔진, 샘플 콘텐츠와 UI를 옮겼습니다. 원본 Android 저장소와 독립된 Git 이력입니다. Pleos 디자인 CSS는 공개 저장소에 포함됩니다. 서체 라이선스는 `assets/fonts/OFL.txt`에 있습니다. 제3자 디자인 자산의 권리를 새로 부여하는 라이선스는 포함하지 않습니다.
